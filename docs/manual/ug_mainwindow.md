# The main window

The window has a menu bar and, below it, a row of tabs. The first tab,
"Database", is always present. Every open load gets a tab of its own. On
Linux the program draws its own title bar with the menu in the title row
(**File** → **Settings** → **Appearance**).

## Menus

- File
  - New load… `Ctrl+N`
  - Open load… `Ctrl+O`
  - Open recent
  - Save `Ctrl+S`
  - Save as…
  - Print preview…
  - Print… `Ctrl+P`
  - Export report as PDF…
  - Overlay reference result… `Ctrl+R`
  - Clear reference overlay
  - Settings… `Ctrl+,`
  - Quit

- Edit
  - Undo `Ctrl+Z`
  - Redo `Ctrl+Shift+Z` or `Ctrl+Y` - Only available in Load dialogs

- View
  - Theme (system default, light, dark)
    - System Default
    - Light
    - Dark
  - Language - A language change takes effect after a restart

- Tools
  - Burn rate table…
  - Unit converter…

- Help
  - User manual `F1` - opens this manual as a PDF
  - Online documentation
  - About ChamberSimReloaded…

## Layout

The panels are separated by splitters (the small dotted handles) that
you can drag. The program remembers the splitter positions, the column
widths of the property tables and the window geometry.
